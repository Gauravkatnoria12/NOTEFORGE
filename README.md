# 📝 NOTEFORGE

**NOTEFORGE** is an AI-powered notes and tasks management application designed to help you organize, create, and store your thoughts, ideas, and tasks in one unified workspace. Similar to Notion, NOTEFORGE combines the power of AI with an intuitive interface to streamline your productivity.

## ✨ Features

- 📌 **Create & Manage Notes** - Write, edit, and organize your notes with ease
- ✅ **Task Management** - Create tasks, set priorities, and track your progress
- 🤖 **AI-Powered Assistant** - Leverage AI capabilities to enhance your note-taking experience
- 📂 **Organize Workspaces** - Structure your content with folders and collections
- 🔍 **Search & Filter** - Quickly find notes and tasks using powerful search functionality
- 💾 **Auto-Save** - Your work is automatically saved to ensure you never lose data
- 🎨 **Clean UI** - Beautiful and intuitive user interface for seamless workflow
- 📱 **Responsive Design** - Access your notes on desktop and mobile devices

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- Python (v3.7 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Gauravkatnoria12/NOTEFORGE.git
   cd NOTEFORGE
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Python environment** (if applicable)
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. **Start the application**
   ```bash
   npm start
   ```

5. **Access the app**
   Open your browser and navigate to `http://localhost:3000`

## 💡 Usage

### Creating a Note
1. Click on the "New Note" button
2. Enter your title and content
3. Use rich text formatting options
4. Auto-save will preserve your work

### Managing Tasks
1. Navigate to the Tasks section
2. Click "Add Task" to create a new task
3. Set priority, due date, and descriptions
4. Mark tasks as complete when finished

### Using AI Features
- Ask AI to summarize your notes
- Generate ideas and expand on existing content
- Organize and categorize your notes automatically
